# 🌱 Pedh Lagao – Gardening E-commerce Website

Pedh Lagao is a full-stack gardening e-commerce website that allows users to explore and purchase a variety of plants online. It provides a user-friendly shopping experience with product management, cart functionality, and online payment integration.

### ✨ Features
- Browse plants with images, descriptions, and prices.
- Add plants to the shopping cart.
- Secure online payments using Stripe.
- Admin dashboard for managing products.

### 🛠️ Tech Stack
React.js, Node.js, Express.js, MongoDB, Cloudinary, Stripe.
